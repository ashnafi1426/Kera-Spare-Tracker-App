## Screen Mapping Index

Every one of the 56 Stitch screens is cataloged, mapped against existing Flutter screens/components, analyzed for required changes, and assigned an implementation status:
- **`EXISTS_NEEDS_RESTYLE`**: Screen exists in Flutter; business logic is functional; UI needs updating to match Stitch design tokens and layout.
- **`NEEDS_NEW_ROUTE`**: Screen represents a distinct Stitch view currently missing or embedded in a modal; requires a dedicated GoRouter route.
- **`REUSABLE_COMPONENT`**: Represents a modal sheet, dialog, or UI state component rather than an entire full-screen page.
